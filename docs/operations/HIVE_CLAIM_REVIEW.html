Reviewed invariants

Inspected proportional arithmetic and decimal conversion; snapshot/Merkle bounds; source and destination signature binding; immutable recipient; signer/account/PDA checks; permanent claim records; funded reservations; cancellation before refunds; exact token transfers; durable submission journal. No additional exploitable defect was identified in this review scope. The bridge remains dependent on the single admin verifier correctly attesting finalized remote-chain state.

Evidence and limits

49 JavaScript tests, TypeScript, 24 EVM tests (two fuzz tests with 256 cases each), 10 Solana native runtime tests and 2 Rust interop/arithmetic tests passed. The EVM live fork test was skipped. Rust emitted existing deprecation/dead-code warnings. Native runtime tests do not establish deployed SBF compute usage. Follow-up: 17 Chrome checks passed for amount controls and responsive layouts in both themes, using mocked balances; no live-wallet execution. Seven quote/intake/observer tests and TypeScript also passed after adding the pre-signature quote module. The full repository suite was not rerun; prior unrelated security-regression failures remain outside this verification.

Assessment

Local implementation: security B, correctness B, error handling B, testing B, organization B, documentation B. Overall B, provisional within the inspected scope. Ready for mainnet: no.

Integration follow-up

The wallet UI, authenticated operator gateway, website proxy and durable deposit/status integration are now implemented locally. Current validation: 53 JavaScript tests, TypeScript, scoped lint, production build, and 28 production-browser fixture checks passed. See the handoff for deployment topology, recovery limitations and launch requirements. No live migration was executed.
