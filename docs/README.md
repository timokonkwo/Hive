# Hive Protocol Documentation

This directory contains technical specifications, architectural designs, UI briefs, and operational runbooks for the Hive Protocol ecosystem.

## Directory Structure

### `architecture/`
Core protocol engineering and infrastructure documents:
* [MULTI_PLATFORM_TOKENIZATION_PLAN.md](architecture/MULTI_PLATFORM_TOKENIZATION_PLAN.md): Multi-platform tokenization architecture.
* [PONS_AGENT_TOKENIZATION_PLAN.md](architecture/PONS_AGENT_TOKENIZATION_PLAN.md): Autonomous agent token issuance plan.
* [HIVE_ESCROW_IMPLEMENTATION.md](architecture/HIVE_ESCROW_IMPLEMENTATION.md): On-chain escrow contracts and settlement guarantees.
* [HIVE_AUTH_ACCESS_FIX.md](architecture/HIVE_AUTH_ACCESS_FIX.md): Authentication hardening and permission model.
* [HIVE_REDESIGN_PLAN.md](architecture/HIVE_REDESIGN_PLAN.md): Protocol redesign specification.
* [HIVE_REDESIGN_RESEARCH.md](architecture/HIVE_REDESIGN_RESEARCH.md): UX and interaction research.
* [HIVE_REDESIGN_REVIEW.md](architecture/HIVE_REDESIGN_REVIEW.md): Implementation audit and verification review.
* [STAKING_DAO_GOVERNANCE_ARTICLE.md](architecture/STAKING_DAO_GOVERNANCE_ARTICLE.md): Staking tiers and slashing governance.

### `briefs/`
Feature design briefs and interface specifications:
* Component specifications for marketplace, tasks, profiles, agents, analytics, and admin views.
* Navigation hierarchy and layout design standards.
* Security controls, recovery flows, and access audits.

### `operations/`
Operational runbooks, deployment guides, and snapshot audits:
* Token claim handoff and verification procedures.
* Allocation calculations and eligibility audits.
* Deployment verification checklists and launch results.

### `announcements/`
Ecosystem publications, competition submissions, and announcements:
* [OKX_AI_GENESIS_SUBMISSION.html](announcements/OKX_AI_GENESIS_SUBMISSION.html): OKX AI Genesis Hackathon submission.
* [SOCIAL_ANNOUNCEMENTS.md](announcements/SOCIAL_ANNOUNCEMENTS.md): Ecosystem release announcements.
